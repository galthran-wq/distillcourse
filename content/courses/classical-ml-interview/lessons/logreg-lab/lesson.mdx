Everything this module derived on the whiteboard — the sigmoid from log-odds,
cross-entropy from the Bernoulli likelihood, the $(p - y)x$ gradient, L2
against divergence on separable data — becomes running code here. You build
logistic regression from scratch in numpy, checkpoint by checkpoint, and then
turn it on real data: the Wisconsin breast-cancer diagnostic set, with the
holdout labels kept on the course server.

The lab runs as a Jupyter notebook — open it in Colab with the button below,
or run it in any Jupyter you like. Pair the notebook with the code from this
page; each checkpoint submits your function's outputs for verification and
the checklist below tracks what stands. Five checkpoints are required; the
open modeling task and the written answer are optional — partial completion
is a normal way to finish a lab.

Expect three to five hours of real work. The first checkpoints are warm-ups;
the trainer and the open task are not. If a check goes red, the verdict often
names the exact bug — read it before rereading your code.

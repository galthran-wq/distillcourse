Everything this module derived on the whiteboard — the sigmoid from log-odds,
cross-entropy from the Bernoulli likelihood, the gradient you will now derive
again yourself, L2 against divergence on separable data — becomes running
code here. You build logistic regression from scratch in numpy, checkpoint by
checkpoint, and then turn it on real data: the Wisconsin breast-cancer
diagnostic set (Wolberg, Street & Mangasarian, UCI, 1993), with the holdout
labels kept on the course server.

The lab runs as a Jupyter notebook — open it in Colab with the button below,
or in any Jupyter you like. Pair the notebook with the code from this page;
each checkpoint submits your function's outputs for verification and the
checklist below tracks what stands. Six of the nine checkpoints are required;
Newton's method, the open modeling task and the written answer are optional —
partial completion is a normal way to finish a lab.

Expect four to five hours of real work: the derivations are asked for, not
printed, and two checkpoints are interview exercises in their own right —
Newton/IRLS with a hand-derived Hessian, and ROC-AUC implemented as a rank
statistic. If a check goes red, the verdict often names the exact bug — read
it before rereading your code.

The AUC you implement here — and then try to beat — is defined, dissected and
traded off against its alternatives in <Ref lesson="classification-metrics" />.

If H(X|Y) bits of uncertainty about X remain after observing Y, then no rule
for guessing X from Y — however clever — can have an error probability below
the value Fano's inequality fixes. This lesson computes both quantities on a
four-symbol channel, states the inequality, proves it by expanding one
conditional entropy two ways, inverts it into an error floor, and exhibits the
distribution that meets it exactly.

The course's argument has been accumulating statements about bits.
<Ref lesson="mutual-information"/> measured what one variable says about
another, and <Ref lesson="data-processing-inequality"/> showed that no
processing stage can add to it, leaving every pipeline under a fixed ceiling.
Both results are stated in bits, and an engineer is not judged in bits: the
deliverable is an error rate. This lesson supplies the conversion, and the
conversion runs one way only, from leftover uncertainty to a floor on errors
that holds for every decoder ever written. Every impossibility result in the
rest of the course, starting with the converse of the
<Ref lesson="noisy-channel-coding">noisy-channel coding theorem</Ref>, is this
inequality plus the data-processing inequality and nothing else.

## Every decoder at once: what the bound quantifies over

The setup is the one an engineer already has. A quantity $X$ is unknown, an
observation $Y$ is available, and some rule turns the second into a guess at
the first.

<Task>
Answer these from memory before reading on. (1) State what $H(X \mid Y) = 0$
says about the pair $(X, Y)$. (2) Give the largest value $H(X \mid Y)$ can
take when $X$ ranges over $m$ symbols, and the joint distribution attaining
it. (3) Write the binary entropy function $H_2(p)$ and its value at
$p = \tfrac{1}{4}$.
</Task>

<Aside>
(1) $X$ is a function of $Y$: every observation determines the answer, so a
zero-error guessing rule exists. (2) $\log_2 m$, attained when $X$ is uniform
and independent of $Y$, since $H(X \mid Y) \le H(X) \le \log_2 m$ chains
conditioning-reduces-entropy (<Ref lesson="joint-and-conditional-entropy"/>)
with the range theorem (<Ref lesson="entropy-as-average-surprise"/>). (3)
$H_2(p) = -p\log_2 p - (1-p)\log_2(1-p)$, and
$H_2(\tfrac{1}{4}) \approx 0.811$ bits.
</Aside>

### The setup: $X$, $Y$, and any rule at all

<Definition title="the guessing problem">
Let $X$ take values in a finite alphabet $\mathcal{X}$ of size
$M = |\mathcal{X}|$, let $Y$ be an observation jointly distributed with $X$,
and let $\hat{X} = g(Y)$ be produced from $Y$ by any rule $g$, deterministic
or randomized, so that $X \to Y \to \hat{X}$ is a Markov chain. The **error
probability** of that rule is
$$
P_e = \Pr\bigl[\hat{X} \ne X\bigr].
$$
</Definition>

<Figure
  src="./figures/setup.svg"
  alt="A chain from X through a channel p(y given x) to Y, then through a guessing rule g to X-hat, with H(X given Y) bracketed over the first half and the error probability marked on a dashed return path from X-hat to X"
  caption="Two labelled quantities on one diagram: the bound relates them and never mentions g."
/>

The Markov condition is not a restriction on the engineer; it is the statement
that the guess is computed from the observation and from nothing else. Every
decoder, classifier, estimator and lookup table satisfies it, as does any rule
that consults a random number generator, because
<Ref lesson="data-processing-inequality">the data-processing
inequality</Ref> established that fresh noise independent of $(X, Y)$ leaves
the chain intact.

### The bound prices the problem, not the algorithm

That universality is the whole point. The inequality below is proved once,
with no hypothesis on $g$, so it applies simultaneously to the rule you wrote,
the rule you would have written after another month, and the rule nobody has
found. A statement of that shape prices the problem rather than the algorithm.

<KeyFact>
The bound is met by no argument about decoders because it contains no
decoder. Beating it is not difficult; it is a contradiction, in the same way
that beating the entropy floor of
<Ref lesson="source-coding-theorem-lite">the source coding theorem</Ref> with
a lossless code is a contradiction.
</KeyFact>

## 1.357 bits left, 30 percent errors

Take a concrete channel and compute both quantities before asking how they are
related.

### Four steps on a four-key channel

<Example title="the four-key channel">
$X$ is uniform on $\{1,2,3,4\}$, so $H(X) = 2$ bits. The channel outputs
$Y = X$ with probability $0.7$ and each of the three other values with
probability $0.1$.

**Step 1: the posterior.** The channel is symmetric and the input is uniform,
so $Y$ is uniform too and Bayes' rule gives, for each observed $y$,
$$
p(x \mid y) = 0.7 \text{ at } x = y, \qquad 0.1 \text{ at each of the other
three symbols.}
$$

**Step 2: leftover uncertainty.** Every observation leaves the same posterior
shape, so the average is that one distribution's entropy:
$$
H(X \mid Y) = 0.7\log_2\frac{1}{0.7} + 3 \times 0.1 \log_2\frac{1}{0.1}
= 0.360 + 0.997 = 1.357 \text{ bits.}
$$
The observation removed $I(X;Y) = 2 - 1.357 = 0.643$ bits of the two that were
there.

**Step 3: the best decoder.** The rule that maximizes the posterior picks
$\hat{X} = Y$, and it is wrong exactly when the channel moved the symbol:
$P_e = 0.3$. No other rule does better, because on every observation it would
have to pick a symbol of posterior mass $0.1$ instead of $0.7$.

**Step 4: the coincidence.** Evaluate the binary entropy of that error
probability, and add the error probability times the log of the number of
wrong symbols:
$$
H_2(0.3) + 0.3\log_2 3 = 0.881 + 0.475 = 1.357 \text{ bits,}
$$
the same number as Step 2, to three decimals.
</Example>

<Figure
  src="./figures/posterior-four.svg"
  alt="Bar chart of the posterior 0.1, 0.7, 0.1, 0.1 over four symbols, with the tallest bar marked as the best guess and the three short bars braced as 0.3 of the mass"
  caption="What every observation leaves: 0.7 on one symbol, 0.1 on each of the other three, so 30% of guesses miss."
/>

The agreement in Step 4 is exact, not approximate, and it is not a property of
this channel. The two expressions are the two sides of an inequality that
happens to be tight here, and the inequality itself holds for every joint
distribution and every rule.

### The same four steps on an uneven posterior

<Exercise>
Run the same four steps on a different channel over the same alphabet, one
whose posterior is $p(x \mid y) = (0.5,\, 0.3,\, 0.1,\, 0.1)$ for every
observed $y$, ordered so that the mass $0.5$ sits on a different symbol for
each $y$. Compute $H(X \mid Y)$, the best decoder's $P_e$, and the quantity
$H_2(P_e) + P_e \log_2 3$. Report which of the last two is larger, and by how
much. Write down your prediction of the direction before computing.

<Solution>
**Leftover uncertainty.**
$$
H(X \mid Y) = 0.5 \times 1 + 0.3\log_2\frac{10}{3}
+ 2 \times 0.1 \log_2 10 = 0.500 + 0.521 + 0.664 = 1.685 \text{ bits.}
$$

**Best decoder.** Pick the posterior mode, the symbol holding $0.5$; it is
wrong with probability $P_e = 0.5$.

**The other side.** $H_2(0.5) + 0.5\log_2 3 = 1 + 0.792 = 1.792$ bits.

**Comparison.** $1.792 > 1.685$, so the second expression exceeds
$H(X \mid Y)$ by $0.107$ bits: the relation is an inequality here, not an
equality. Read as a constraint on $P_e$ it is weaker than the truth. Solving
$H_2(p) + p\log_2 3 = 1.685$ gives $p = 0.44$, so the bound forbids only
$P_e < 0.44$ while the real best decoder sits at $0.50$. The transferable
move: equality in Step 4 of the worked example came from the posterior's shape
(one large mass, the rest equal), and flattening the wrong symbols unevenly
opens a gap.
</Solution>
</Exercise>

## The proof: one entropy, two expansions

The relation to prove is that the quantity computed in Step 4 is never smaller
than the leftover uncertainty. The proof is short and uses one device: a
binary variable that records only whether the guess was wrong, whose entropy
is $H_2(P_e)$ by construction.

### The statement, and the weak form used for quick estimates

<Theorem title="Fano's inequality (Cover &amp; Thomas 2.10.1)">
Let $X$ take values in $\mathcal{X}$ with $M = |\mathcal{X}|$, let
$X \to Y \to \hat{X}$ with $\hat{X}$ taking values in $\mathcal{X}$, and let
$P_e = \Pr[\hat{X} \ne X]$. Then
$$
H(X \mid Y) \;\le\; H(X \mid \hat{X}) \;\le\; H_2(P_e) + P_e \log_2 (M - 1).
$$
Weakening $H_2(P_e) \le 1$ and $\log_2(M-1) \le \log_2 M$ gives the form used
for quick estimates,
$$
P_e \;\ge\; \frac{H(X \mid Y) - 1}{\log_2 M}.
$$

<Proof>
The plan is three steps: define the error indicator, expand one conditional
entropy along two different orders, and bound the two terms of the second
expansion. Only the last step uses the alphabet size.

**Step 1, the indicator.** Define the binary variable
$$
E = \mathbf{1}\{\hat{X} \ne X\}, \qquad \Pr[E = 1] = P_e,
$$
so $H(E) = H_2(P_e)$.

**Step 2, two expansions.** The chain rule for entropy from
<Ref lesson="joint-and-conditional-entropy">joint and conditional
entropy</Ref> splits the joint conditional entropy $H(E, X \mid \hat{X})$ in either order:
$$
H(E, X \mid \hat{X}) = H(X \mid \hat{X}) + H(E \mid X, \hat{X})
= H(E \mid \hat{X}) + H(X \mid E, \hat{X}).
$$
The second term of the first expansion vanishes: $E$ is the function
$\mathbf{1}\{\hat{X} \ne X\}$ of the pair $(X, \hat{X})$, and a variable
determined by its conditioning has zero conditional entropy. So
$$
H(X \mid \hat{X}) = H(E \mid \hat{X}) + H(X \mid E, \hat{X}).
$$

**Step 3, bound the two survivors.** Conditioning reduces entropy on average,
so $H(E \mid \hat{X}) \le H(E) = H_2(P_e)$. The remaining term splits on the
value of $E$:
$$
H(X \mid E, \hat{X}) = (1 - P_e)\, H(X \mid \hat{X}, E{=}0)
+ P_e\, H(X \mid \hat{X}, E{=}1).
$$
Given $E = 0$ the guess was right, so $X = \hat{X}$ is determined and the
first conditional entropy is $0$. Given $E = 1$ and given the value of
$\hat{X}$, the true symbol is one of the $M - 1$ symbols that are not
$\hat{X}$, and the entropy of a variable on $M-1$ values is at most
$\log_2(M-1)$. Hence
$$
H(X \mid \hat{X}) \le H_2(P_e) + P_e \log_2(M-1).
$$

**Step 4, replace $\hat{X}$ by $Y$.** Since $X \to Y \to \hat{X}$ is a Markov
chain, the data-processing inequality gives
$I(X; \hat{X}) \le I(X; Y)$, and subtracting both sides from $H(X)$ turns that
into $H(X \mid \hat{X}) \ge H(X \mid Y)$. Chaining the two displays gives the
theorem.
</Proof>
</Theorem>

### Three checks: where each hypothesis is used

<Task>
Three checks on the proof, in order. First, locate the single step where the
alphabet size enters, and state what the bound would read if the wrong symbol
were known to lie in a set of only $3$ candidates rather than $M-1$. Second,
name the step that would fail if $E$ recorded the *size* of the error rather
than its occurrence. Third, verify Step 3 on the worked example: $P_e = 0.3$,
the wrong symbols number $3$, and both bounds of Step 3 hold with equality
there.
</Task>

The third check answers itself and identifies the tight case. In the four-key
channel $H(E \mid \hat{X}) = H(E) = H_2(0.3)$ because the chance of an error
is the same whatever the guess was, and $H(X \mid \hat{X}, E{=}1) = \log_2 3$
because, conditioned on an error, the true symbol is uniform on the three
others. Both inequalities of Step 3 are equalities, which is why Step 4 of the
worked example produced the same number twice.

<KeyFact>
The $\log_2(M-1)$ rather than $\log_2 M$ costs nothing in a long derivation
and matters enormously at $M = 2$: the term becomes $\log_2 1 = 0$ and the
whole bound collapses to the binary entropy curve, a far stronger statement
than the general form suggests.
</KeyFact>

## Reading the bound backwards: bits become an error floor

The theorem is stated as an upper bound on leftover uncertainty, which is not
the direction anyone uses it. Rearranged, it says that a small error
probability requires small leftover uncertainty, and therefore that a fixed
amount of leftover uncertainty forbids a range of error probabilities
outright.

### The forbidden region above the curve $F$

Write $F(p) = H_2(p) + p\log_2(M-1)$ for the right-hand side as a function of
the error probability. The theorem says the point
$\bigl(P_e,\, H(X \mid Y)\bigr)$ lies on or below the curve $F$, so the region
above the curve contains no achievable pair.

<Figure
  src="./figures/region.svg"
  alt="The curve H2(Pe) plus Pe log2 255 rising from the origin, with the region above it shaded as unreachable and a marked point at error probability 0.38 for four bits of conditional entropy"
  caption="Forbidden above, permitted below: with 256 symbols, four leftover bits push the smallest possible error rate to 0.38."
/>

<Example title="a byte with four bits left">
A byte-valued quantity is transmitted, $M = 256$, and the observation leaves
$H(X \mid Y) = 4$ bits — exactly half of the eight the byte could carry.

**The full bound.** Solve $H_2(p) + p \log_2 255 = 4$. Since
$\log_2 255 = 7.994$, the trial $p = 0.38$ gives
$0.958 + 3.038 = 3.996$, just under $4$, and $p = 0.382$ gives $4.013$, just
over. So the smallest permitted error probability is $P_e \ge 0.381$.

**The weak form.** $P_e \ge (4 - 1)/\log_2 256 = 3/8 = 0.375$, computed
without solving anything.

**The gap.** The weak form gives up $0.006$ of error probability here, under
two percent of the value, because the discarded $H_2(P_e) \le 1$ bit is small
against the $8$ bits of $\log_2 M$. The approximation is good exactly when the
alphabet is large.
</Example>

### The same four bits, three alphabet sizes

From "half the bits are gone" one would expect a definite verdict about
errors, and there is none: the same four leftover bits are compatible with
almost any error rate, depending on the alphabet.

<Figure
  src="./figures/same-bits-three-alphabets.svg"
  alt="An error-probability axis with three marked floors for the same four bits of leftover uncertainty: 0.038 for an alphabet of 2 to the 100 symbols, 0.38 for 256 symbols, and 0.94 for 16 symbols"
  caption="Leftover bits are only meaningful against log₂ M: four of them force 4% errors on a huge alphabet and 94% on a small one."
/>

With $M = 16$ the four bits are the entire budget, $\log_2 16 = 4$, so the
bound forces $P_e = 15/16$ exactly: nothing was learned and guessing is all
that is left. With $M = 2^{100}$ the same four bits force only
$P_e \ge 0.038$. A conditional entropy quoted without its alphabet size is
uninterpretable as an error statement.

<Remark title="the curve is not monotone">
$F$ rises to $\log_2 M$ at $p = (M-1)/M$ and then falls back to
$\log_2 (M-1)$ at $p = 1$, so inverting it requires care: the constraint
$F(P_e) \ge H(X \mid Y)$ picks out the smaller root, and that root is the
floor quoted above. At the extreme $H(X \mid Y) = \log_2 M$ the two roots
coincide and the inequality pins $P_e$ to the single value $(M-1)/M$, which is
the $15/16$ of the $M = 16$ case.
</Remark>

<KeyFact>
Reading the bound backwards is what makes the whole apparatus operational: any
argument that produces an upper bound on $I(X;Y)$ produces a lower bound on
$H(X \mid Y) = H(X) - I(X;Y)$, and Fano converts that into an error rate no
system can beat. The <Ref lesson="noisy-channel-coding">next lesson</Ref>
supplies the upper bound on $I(X;Y)$ and reads off the answer.
</KeyFact>

## The binary case: the log term vanishes

The general form carries a $\log_2(M-1)$ that dominates it for large
alphabets. At $M = 2$ that term is zero and the inequality reduces to a
statement about one curve.

$$
H(X \mid Y) \;\le\; H_2(P_e) \qquad (M = 2).
$$

The curve on the right is the binary entropy function that
<Ref lesson="entropy-as-average-surprise">the entropy lesson</Ref> plotted as
the entropy of a biased coin. Here it plays a different role: the argument is an error probability
rather than a coin bias, and the curve is read as a ceiling on how much
uncertainty a given error rate can excuse.

### Half a bit of leftover uncertainty forces 11 percent errors

<Example title="half a bit about one bit">
A binary $X$ is observed through some channel leaving $H(X \mid Y) = 0.5$
bits. The bound requires $H_2(P_e) \ge 0.5$.

$H_2$ is strictly increasing on $[0, \tfrac{1}{2}]$, with
$H_2(0.10) = 0.469$ and $H_2(0.11) = 0.500$. So $P_e \ge 0.11$: better than
one error in ten is impossible, whatever the decoder.

The general form would have given $H_2(P_e) + P_e\log_2 1 \ge 0.5$, the same
thing, since $\log_2 1 = 0$. Applying the *weak* form instead gives
$P_e \ge (0.5 - 1)/1 = -0.5$, which is vacuous: the weak form throws away a
whole bit and there is only one bit here to throw.
</Example>

<Exercise>
A binary variable is observed through a channel leaving $H(X \mid Y) = 0.2$
bits. Give the Fano floor on $P_e$ to two decimals, and state how many times
smaller it is than the floor at $H(X \mid Y) = 0.5$. Then explain, in one
sentence, why halving the leftover uncertainty cuts the permitted error rate
by much more than half.

<Solution>
Solve $H_2(p) = 0.2$ on $[0, \tfrac{1}{2}]$. Trials: $H_2(0.03) = 0.194$ and
$H_2(0.032) = 0.204$, so $P_e \ge 0.031$, which rounds to $0.03$.

Against the $0.11$ of the worked example, the floor fell by a factor of about
$3.5$ while the leftover uncertainty fell by a factor of $2.5$.

The reason is the shape of $H_2$ near zero, established in
<Ref lesson="entropy-as-average-surprise">the entropy lesson</Ref>: the curve
is vertical at the
ends, so a small error probability already buys a disproportionate amount of
entropy. Inverting a function that is steep near the origin gives an inverse
that is flat there, so entropy has to fall a long way before the permitted
error rate moves much, and once it does move, it moves fast.
</Solution>
</Exercise>

## Tightness: the bound is attained, so it cannot be sharpened

An inequality that is never met with equality is a defect waiting for a better
argument. This one is met, and the distribution that meets it is the one the
proof's Step 3 identified.

### The posterior that closes both inequalities

<Theorem title="the equality case">
Fix $M$ and $P_e$. Equality holds in
$H(X \mid \hat{X}) = H_2(P_e) + P_e\log_2(M-1)$ exactly when, for every value
of $\hat{X}$, the conditional distribution of $X$ is
$$
p(x \mid \hat{X}) =
\begin{cases}
1 - P_e & x = \hat{X},\\[2pt]
\dfrac{P_e}{M-1} & \text{each of the other } M-1 \text{ symbols.}
\end{cases}
$$
</Theorem>

Both bounds of Step 3 become equalities under that shape, and only under it.
The error probability is the same for every guess, so conditioning $E$ on
$\hat{X}$ tells nothing and $H(E \mid \hat{X}) = H(E)$; and conditioned on an
error the true symbol is uniform on the $M-1$ alternatives, which is when a
variable on $M-1$ values attains $\log_2(M-1)$.

<Figure
  src="./figures/tight-vs-loose.svg"
  alt="Two four-bar posterior charts side by side: the left with masses 0.1, 0.7, 0.1, 0.1 attaining the bound at error probability 0.30, the right with 0.3, 0.5, 0.1, 0.1 sitting at 0.50 against a bound of 0.44"
  caption="Equality needs the errors spread evenly: uneven wrong-symbol mass leaves 0.06 of slack between the floor and the truth."
/>

The four-key channel of the worked example has exactly that posterior with
$M = 4$ and $P_e = 0.3$, which is why its two computed numbers agreed to three
decimals. Every $(M, P_e)$ pair has such a channel, so the curve $F$ is not
merely an upper envelope: every point on it is realized.

### Why a converse proved through Fano cannot be improved

That is what makes the bound worth carrying into the rest of the course. A
converse proved through Fano cannot be improved by finding a cleverer
argument, because a channel exists on which the inequality is an identity, and
any strictly stronger statement would be false on that channel. The slack in a
particular application is slack in the *other* steps of the derivation, never
in this one.

<Aside>
The reason the equality distribution looks familiar is that it is the
maximum-entropy distribution subject to a fixed mass on one designated symbol.
Polyanskiy and Wu take that as the definition, writing
$F_M(p_{\max}) = (1 - p_{\max})\log(M-1) + h(p_{\max})$ for the largest
entropy a distribution with maximum mass $p_{\max}$ can have, and deriving
Fano's inequality by applying data processing for divergence to the map
$(X, \hat{X}) \mapsto \mathbf{1}\{X = \hat{X}\}$. That route gives the same
curve with no error indicator and no chain rule, and it generalizes to a
version in which the reference distribution is not uniform.
</Aside>

## ★ A floor under every estimator, not only every decoder

Nothing in the proof mentions channels. The same inequality lower-bounds the
risk of any statistical estimator, through a reduction that turns an
estimation problem into a guessing problem. This section is off the main line;
the channel material that follows does not use it.

### The two-point reduction

The reduction, due in this form to Fano and Le Cam, has three moves. Pick two
parameter values far enough apart that a good estimator must be able to tell
them apart. Encode the choice between them in one uniform bit $W$. Then any
estimator with small risk yields a decoder for $W$ with small error, and
Fano's inequality says a decoder for $W$ with small error needs the data to
carry nearly a full bit about $W$.

### The Bernoulli mean: $0.015/n$ against $1/(4n)$

The worked case is estimating the mean of a Bernoulli source from $n$
independent draws under squared-error loss. The empirical mean attains
$$
\sup_{\theta} \mathbb{E}\bigl[(\hat\theta_{\text{emp}} - \theta)^2\bigr]
= \sup_{\theta} \frac{\theta(1-\theta)}{n} = \frac{1}{4n},
$$
and the question is whether some cleverer, possibly biased estimator does
better than $1/n$ order. The Cramér-Rao bound answers only for unbiased
estimators, which is a restriction on the estimator rather than on the
problem. The Fano route has no such restriction: putting the two-point prior
at $\tfrac{1}{2} \pm \kappa\Delta_n$, bounding the induced decoder's error by
Chebyshev's inequality, and bounding $I(W; \hat{W})$ from above by
$I(\theta; X^n)$ with the data-processing inequality gives, after optimizing
over $\kappa$,
$$
R^*(n) \;\ge\; \frac{0.015}{n} + o(1/n).
$$

The two numbers bracket the minimax risk between $0.015/n$ and $0.25/n$: a
factor of about seventeen apart in constant, identical in rate. The empirical
mean is therefore rate-optimal, and no estimator of any kind improves on
$1/n$. The exact minimax risk for this problem is $1/\bigl(4(1+\sqrt{n})^2\bigr)$,
obtained by other methods; the point of the Fano route is that it delivers the
rate from two ingredients this course already owns.

## What the inequality does not license

The bound runs in one direction, and the commonest error is to read it in the
other. Stated plainly: a small value of $H(X \mid Y)$ makes the Fano floor
small, and a small floor is not a decoder.

The false step is the claim that large mutual information implies a good
decoder exists. Fano's inequality says $H(X \mid Y) \le F(P_e)$ for every
rule; it never asserts that some rule attains $F^{-1}$, and in general none
does. The half-revealing channel makes the gap visible: let $X$ be uniform on
four symbols and let $Y$ report only whether $X$ lies in $\{1,2\}$ or
$\{3,4\}$. Then $H(X \mid Y) = 1$ bit, the Fano floor is $P_e \ge 0.19$, and
the best possible decoder errs with probability $0.50$, because after the
observation two symbols remain equally likely and a coin decides. The floor is
off by a factor of two and a half, and the slack sits in the proof's
$\log_2(M-1)$ step, since after an error the true symbol is not uniform on the
three others but is the single symbol paired with the guess.

<KeyFact>
Impossibility and achievability are separate theorems with separate proofs:
Fano constructs no rule and cannot, while an achievability claim needs an
explicit construction or an existence argument over a family of them — here
the random-coding argument of <Ref lesson="noisy-channel-coding"/>, which
works only because a long block lets a code choose which distributions it
faces.
</KeyFact>

Established: for any $X$, any observation $Y$, and any rule computing
$\hat{X}$ from $Y$, the leftover uncertainty obeys
$H(X \mid Y) \le H_2(P_e) + P_e\log_2(M-1)$; inverting it converts leftover
bits into a minimum error rate, and the bound is attained by an explicit
family of posteriors, so it cannot be sharpened. What is still missing is the
upper bound on $I(X;Y)$ that would make the conversion bite for a
communication system. <Ref lesson="channel-capacity">Channel capacity</Ref>
supplies that bound for one channel use, and
<Ref lesson="noisy-channel-coding">the coding theorem</Ref> extends it to $n$
uses and reads off the threshold.

## Exercises

<Exercise>
An alphabet of $32$ symbols is observed through a channel leaving
$H(X \mid Y) = 2$ bits. Compute the Fano floor on $P_e$ from the full form and
from the weak form, and report the gap in percentage points. State which of
the two discarded quantities accounts for most of the gap.

<Solution>
**Full form.** Solve $H_2(p) + p\log_2 31 = 2$ with $\log_2 31 = 4.954$.
At $p = 0.24$: $0.795 + 1.189 = 1.984$. At $p = 0.245$: $0.803 + 1.214 =
2.017$. Interpolating, $P_e \ge 0.242$.

**Weak form.** $P_e \ge (2-1)/\log_2 32 = 1/5 = 0.200$.

**Gap.** $4.2$ percentage points, about a sixth of the value.

**Where it comes from.** The weak form makes two replacements:
$H_2(P_e) \le 1$ and $\log_2 31 \to \log_2 32$. The second is worth
$\log_2(32/31) = 0.046$ bits, negligible. The first discards
$1 - H_2(0.242) = 1 - 0.797 = 0.203$ bits, more than four times as much, and
that bit of slack costs $0.203/\log_2 32 \approx 0.041$ of error probability,
which is essentially the whole gap. The weak form is cheap when $\log_2 M$ is
large enough that one bit does not matter; at $M = 32$ it already matters.
</Solution>
</Exercise>

<Exercise>
Push the bound to both ends of its range. (a) Evaluate what it forces as
$H(X \mid Y) \to 0$, and reconcile the answer with the fact that
$H(X \mid Y) = 0$ means a zero-error rule exists. (b) Evaluate it at
$H(X \mid Y) = \log_2 M$, state the exact value of $P_e$ it permits, and check
that value against the error rate of the best rule that ignores $Y$ entirely
and guesses.

<Solution>
**(a) The low end.** $F(P_e) \ge H(X \mid Y)$ becomes $F(P_e) \ge 0$, which
every $P_e$ satisfies since $F \ge 0$ everywhere. The bound is vacuous, and
correctly so: it says only that zero error is *not forbidden*. That a
zero-error rule actually exists is a separate fact, from
<Ref lesson="joint-and-conditional-entropy"/>: $H(X \mid Y) = 0$ means $X$ is
a function of $Y$, and that function is the decoder. Fano is a converse and
never produces a decoder; the existence here comes from elsewhere.

**(b) The high end.** $F$ attains its maximum $\log_2 M$ at
$p = (M-1)/M$ and nowhere else. So $F(P_e) \ge \log_2 M$ forces
$P_e = (M-1)/M = 1 - 1/M$ exactly, an equality rather than a bound, and it is
the one situation in which Fano's inequality pins the error rate from both
sides.

**The check.** $H(X \mid Y) = \log_2 M$ requires $H(X) = \log_2 M$ and
$I(X;Y) = 0$, so $X$ is uniform and independent of $Y$. Any rule then picks a
symbol whose posterior mass is $1/M$, and errs with probability $1 - 1/M$. The
bound and the truth agree exactly, which is consistent with the tightness
result: the uniform posterior is the equality distribution with
$P_e = 1 - 1/M$.
</Solution>
</Exercise>

<Exercise>
Break this claim, then repair it. "The half-revealing channel misses the Fano
floor only because its $\log_2(M-1)$ term is slack, so on a binary alphabet,
where that term vanishes, the floor is the error probability of the best
rule." Refute it on the erasure channel — $X$ a uniform bit, $Y = X$ with
probability $\tfrac{1}{2}$ and $Y = \,?$, an erasure symbol carrying no
information about $X$, with probability $\tfrac{1}{2}$ — by computing
$H(X \mid Y)$, the Fano floor, and the true error probability of the best
rule. Then name which inequality inside the proof carries the slack here, and
name which half of the noisy-channel coding theorem does support an existence
claim. Write down which step you expect to be loose before computing.

<Solution>
**The three numbers.** Given $Y \in \{0,1\}$ the bit is known, and given an
erasure it is uniform, so
$H(X \mid Y) = \tfrac{1}{2}\times 0 + \tfrac{1}{2} \times 1 = 0.5$ bits. With
$M = 2$ the bound reads $H_2(P_e) \ge 0.5$, whose floor is $P_e \ge 0.11$ —
the same value the worked example of the binary section produced. The best
rule outputs $Y$ when it arrives and flips a fair coin on an erasure, so it
errs only on an erased-and-mis-guessed symbol: $P_e = 0.5 \times 0.5 = 0.25$,
larger than the floor by a factor of about $2.3$.

**Which inequality is slack.** Not the alphabet-size one: at $M = 2$ the term
$P_e\log_2(M-1)$ is identically zero, so it cannot contribute. Take the
randomizing rule above and collect the joint mass on $\hat{X} = 0$: the true
bit is $0$ with probability $0.25$ (unerased) plus $0.125$ (erased, coin
right), and $1$ with probability $0.125$ (erased, coin wrong), so the
posterior is $0.75$ against $0.25$ and
$H(X \mid \hat{X}) = H_2(0.25) = 0.811$ bits, exactly the right-hand side
$H_2(P_e)$: Step 3 of the proof is tight. All $0.311$ bits of slack sit in
Step 4, $H(X \mid Y) \le H(X \mid \hat{X})$, the data-processing step — the
rule is forced to emit a symbol of $\mathcal{X}$ and thereby destroys the one
thing $Y$ told it, namely that it does not know.

**Why that is the different failure.** In the body's four-symbol channel the
data-processing step was tight ($H(X \mid \hat{X}) = H(X \mid Y) = 1$ bit) and
the $\log_2(M-1)$ step was slack. Here the two swap. A floor can therefore be
unattainable for at least two independent reasons, and neither is repaired by
making $I(X;Y)$ larger: with erasure probability $\varepsilon$ the floor is
$H_2^{-1}(\varepsilon)$ and the truth is $\varepsilon/2$, and the gap widens as
$\varepsilon$ falls — at $\varepsilon = 0.1$ the floor is $0.013$ against a
true $0.05$, a factor of nearly four where $\varepsilon = 0.5$ gave $2.3$.

**The repair.** Achievability is a separate theorem. The random-coding half of
<Ref lesson="noisy-channel-coding"/> proves that for a channel used $n$ times,
rates below capacity admit codes with vanishing error; it works by choosing
the input distribution and the codebook, degrees of freedom that a single
fixed pair $(X, Y)$ does not have. The transferable move: whenever a bound is
quoted as evidence that something is possible, check which direction the
inequality runs.
</Solution>
</Exercise>

<Exercise>
Prove the binary case directly, without the error indicator or the chain rule.
Take $M = 2$ and any rule $\hat{X} = g(Y)$, and show
$H(X \mid Y) \le H_2(P_e)$ using only that conditioning reduces entropy. Then
invert it to $P_e \ge H_2^{-1}\bigl(H(X \mid Y)\bigr)$ and state why the
inverse is well defined only on $[0, \tfrac{1}{2}]$, and why that restriction
costs nothing.

<Solution>
**The direct argument.** $\hat{X}$ is a function of $Y$, so conditioning on
$Y$ is at least as informative as conditioning on $\hat{X}$:
$H(X \mid Y) \le H(X \mid \hat{X})$. Now, for binary variables,
$X = \hat{X} \oplus E$ where $E = \mathbf{1}\{X \ne \hat{X}\}$, so given
$\hat{X}$ the variable $X$ is determined by $E$ and conversely; hence
$H(X \mid \hat{X}) = H(E \mid \hat{X}) \le H(E) = H_2(P_e)$, the last step
being conditioning-reduces-entropy again. Chaining,
$H(X \mid Y) \le H_2(P_e)$. No chain rule and no alphabet-size bound were
used: with two symbols, "not $\hat{X}$" names a single symbol.

**The inversion.** $H_2$ is continuous, strictly increasing from $0$ to $1$ on
$[0, \tfrac{1}{2}]$ and symmetric about $\tfrac{1}{2}$, so it is two-to-one on
$[0,1]$ and has no inverse there. Restricted to $[0, \tfrac{1}{2}]$ it is a
bijection onto $[0,1]$, and $H_2^{-1}$ denotes that branch. The constraint
$H_2(P_e) \ge H(X \mid Y)$ therefore reads
$H_2^{-1}(H(X \mid Y)) \le P_e \le 1 - H_2^{-1}(H(X \mid Y))$.

**Why the restriction is free.** The upper half of that interval is not a real
restriction, because any binary rule with $P_e > \tfrac{1}{2}$ can be replaced
by its negation, which has error $1 - P_e < \tfrac{1}{2}$. Optimizing over
rules therefore always lands in $[0, \tfrac{1}{2}]$, where the lower branch is
the only one that binds.
</Solution>
</Exercise>

<Exercise>
Construct a joint distribution over an alphabet of $M = 5$ symbols attaining
Fano's inequality with equality at $P_e = 0.4$, verify both sides numerically
to three decimals, and then name which two inequalities inside the proof your
construction turns into equalities and what feature of the construction does
it in each case.

<Solution>
**The construction.** Let $Y$ be uniform on $\{1,\dots,5\}$ and let the
conditional law of $X$ given $Y = y$ put $0.6$ on $x = y$ and $0.1$ on each of
the four other symbols. The rule $\hat{X} = Y$ is optimal and errs with
probability $P_e = 0.4$.

**Left side.** Every observation leaves the same posterior shape, so
$$
H(X \mid Y) = 0.6\log_2\frac{1}{0.6} + 4 \times 0.1\log_2\frac{1}{0.1}
= 0.442 + 1.329 = 1.771 \text{ bits.}
$$

**Right side.** $H_2(0.4) + 0.4\log_2 4 = 0.971 + 0.800 = 1.771$ bits. The two
agree to three decimals.

**Which inequalities close.** First, $H(E \mid \hat{X}) \le H(E)$ becomes an
equality because the error probability is $0.4$ for every value of $\hat{X}$,
so $E$ is independent of the guess and conditioning on it removes nothing.
Second, $H(X \mid \hat{X}, E{=}1) \le \log_2(M-1)$ becomes an equality because
conditioned on an error the four wrong symbols carry mass $0.1$ each, so $X$
is uniform on them and a uniform distribution on $M-1$ values is the only one
attaining $\log_2(M-1)$. Symmetry across $y$ delivers the first, flatness
across the wrong symbols the second.
</Solution>
</Exercise>

<Exercise>
Take a classification dataset you have with $k$ classes, and estimate
$H(\text{label} \mid \text{features})$ honestly: discretize one or two
features into a modest number of bins, build the joint table by counting, and
compute the conditional entropy as the weighted average of the per-cell label
entropies. Report the Fano floor on the error rate that follows, then train any
classifier you like on the same features and report its best test error.
State what you would conclude if the measured error fell below the floor.

<Solution>
**What to compute.** With $n$ rows and bins $b$, the plug-in estimate is
$\hat{H}(\text{label} \mid \text{features}) = \sum_b \hat{p}(b)\,
\hat{H}(\text{label} \mid b)$, exactly the row-weighted average of
<Ref lesson="joint-and-conditional-entropy">the conditional-entropy
lesson</Ref>. Feed it into
$P_e \ge$ the smaller root of $H_2(p) + p\log_2(k-1) = \hat{H}$.

**What to expect.** The floor will almost always sit well below the classifier's
test error, for two reasons that pull the same way. The floor is a converse and
need not be attained, as the half-revealing channel of this lesson shows; and
the plug-in conditional entropy is biased *downward* when cells are sparse,
because a cell with three rows of one class reports zero entropy whatever the
truth. Both effects make the floor look loose.

**If the measured error falls below the floor.** The bound is a theorem, so
the violation is in the measurement. The ranked suspects: (i) the entropy
estimate is too high, unlikely given the downward bias, unless the binning
destroyed a feature the classifier still sees, which is the usual cause —
the classifier reads the unbinned feature and the entropy was computed on the
binned one, so the two quantities are not about the same $Y$; (ii) the test
error is optimistic through leakage or through tuning on the test split;
(iii) the two numbers were computed on different subsets. Check (i) first by
recomputing the classifier's error on the binned features alone, which restores
the comparison the theorem is about. Systematically, entropy estimated from
finite samples is treacherous in both directions, the subject of
<Ref lesson="estimating-mutual-information"/>.
</Solution>
</Exercise>

<Exercise>
A code sends one of $2^{nR}$ equally likely messages $W$ over $n$ uses of a
channel, producing $X^n$, receiving $Y^n$, and decoding $\hat{W} = g(Y^n)$
with block error probability $P_e^{(n)}$. You may use, without proof, that a
memoryless channel of capacity $C$ satisfies $I(X^n; Y^n) \le nC$. Derive an
inequality relating $R$, $C$, $n$ and $P_e^{(n)}$, and state what it forces
when $P_e^{(n)} \to 0$.

<Solution>
**Set up the chain.** $W \to X^n \to Y^n \to \hat{W}$ is a Markov chain: the
codeword is a function of the message, the output is the channel's response,
and the decoded message is computed from the output.

**Split the message entropy.** $W$ is uniform on $2^{nR}$ values, so
$H(W) = nR$, and
$$
nR = H(W \mid Y^n) + I(W; Y^n).
$$

**Bound the first term with Fano.** The alphabet of $W$ has $M = 2^{nR}$
symbols, so the weak form gives
$H(W \mid Y^n) \le 1 + P_e^{(n)}\log_2 2^{nR} = 1 + P_e^{(n)} nR$.

**Bound the second with data processing.**
$I(W; Y^n) \le I(X^n; Y^n) \le nC$, the first step because
$W \to X^n \to Y^n$ and the second by the assumption granted.

**Combine.** $nR \le 1 + P_e^{(n)} nR + nC$, that is
$$
R \;\le\; \frac{1}{n} + P_e^{(n)} R + C,
\qquad\text{equivalently}\qquad
P_e^{(n)} \;\ge\; 1 - \frac{C}{R} - \frac{1}{nR}.
$$

**What it forces.** If $P_e^{(n)} \to 0$ as $n$ grows, the middle term
vanishes and so does $1/n$, leaving $R \le C$. Read the other way, any rate
strictly above capacity has an error probability bounded away from zero by
$1 - C/R$, no matter how long the block or how ingenious the code.

You have just proved the converse of the noisy-channel coding theorem. It is
stated and used in <Ref lesson="noisy-channel-coding"/>, where the remaining
work is the other half: showing that every rate below $C$ *is* achievable, and
the single-letter bound $I(X^n;Y^n) \le nC$ assumed here.
</Solution>
</Exercise>
